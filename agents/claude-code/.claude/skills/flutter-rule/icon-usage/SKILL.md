# Iconの使用

## 方針

Flutterの`Icon`は多用せず、ユーザーが意味を理解するために必要な箇所に限定する。アイコンを置くこと自体を装飾目的にしない。

## 遵守事項

- 画面上の操作や状態を明確に伝える場合だけ使用する。
- `TextButton.icon`など、Iconを内包するウィジェットも同じ基準で判断する。
- ラベルだけで意味が明確なボタンには、アイコンを追加しない。
- アイコンを使う場合も、テキストラベルやアクセシビリティ情報を損なわない。
- 必要性が不明な場合は、アイコンなしの構成を優先する。

## 避けること

- 余白を埋めるためのアイコン追加。
- すべてのボタンへ機械的にアイコンを付けること。
- 意味が曖昧で、操作内容を誤解させるアイコンの採用。

## チェックリスト

- アイコンを除いても操作の意味が明確か確認する。
- アイコンが示す操作や状態を説明できるか確認する。
- `Icon`、`IconButton`、`TextButton.icon`を変更前後で数え、不要な追加がないか確認する。
